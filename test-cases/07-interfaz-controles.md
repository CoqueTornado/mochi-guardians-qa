# Casos de Prueba — 07. Interfaz de Usuario y Controles

Casos de prueba **manuales** de la adaptación horizontal/vertical, el esquema táctil y la pausa.

**Entorno de estos casos.** Windows + Firefox. «Vertical» significa un **viewport de navegador que imita un móvil** (por ejemplo, el modo de diseño adaptable de Firefox con un tamaño de móvil). **No hay prueba en un dispositivo físico**; véase `docs/test-plan.md`.

**Estado de ejecución.** Resultado esperado contrastado con el código (commit `f19a39a`); ejecución manual registrada abajo.

> Nota sobre TC-UI-02: la validación con un dedo real requiere hardware físico no disponible. Se complementa con 43 comprobaciones automatizadas en `test:touch` que cubren las constantes y la lógica de detección. Estado aceptado como **Pass con restricción** (justificado en `docs/test-plan.md` §6 Riesgos).
