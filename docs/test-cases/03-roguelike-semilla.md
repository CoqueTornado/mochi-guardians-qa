# Casos de Prueba — 03. La Gran Grieta (modo roguelike por semilla)

Casos de prueba **manuales** del modo roguelike: mapa de 6 profundidades generado por semilla, elección de camino, reliquias que solo duran una expedición, derrota con recompensa reducida y conservación de la expedición al recargar.

**Estado de ejecución.** Resultado esperado contrastado con el código (commit `f19a39a`); ejecución manual todavía no registrada: «Resultado obtenido» en `[PENDIENTE]`, estado «No ejecutado». El determinismo del generador (misma semilla, mismo mapa) **no** se prueba a mano: no se ha localizado en la interfaz ninguna entrada de semilla, y lo cubre `npm run test:labyrinth` (véase `docs/automation.md`).
