# Actualización — 19/10/2026

El botón de idioma abre un popup con cinco banderas dibujadas por código y los nombres Español, English, Русский, 日本語 y 简体中文. Los nombres se conservan en su propio idioma. Abrir, cancelar o elegir el idioma actual no modifica la preferencia. La selección directa guarda el idioma y reconstruye la escena con el mismo flujo anterior.

La etiqueta rusa de zoom se acorta a «Масштаб», conservando tamaño de letra y función del control.
